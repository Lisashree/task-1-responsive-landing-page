# Task 1: Responsive Landing Page (HTML & CSS)

A clean, responsive landing page with a header, hero section and footer, built for the Web Development Internship (Elevate Labs).

## What I built
- **Header:** logo and navigation links. On small screens the links collapse into a menu button (CSS only, no JavaScript).
- **Hero:** heading, paragraph, two call-to-action buttons, and a small page-layout sketch drawn with CSS Grid.
- **Features section:** three cards in an auto-fitting Grid.
- **Footer:** copyright line and social links.

## Concepts used
- HTML5 semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS Flexbox (header, buttons, footer) and CSS Grid (hero, cards)
- Mobile-first media queries at 768px and 992px
- CSS variables, `clamp()` for fluid type, focus styles, skip link, reduced-motion support

## Files
```
index.html   page structure
style.css    all styling
README.md    this file
```

## How to run
1. Open the folder in VS Code.
2. Right-click `index.html` and choose **Open with Live Server**.
3. Resize the browser window to see the layout change.

## What I learned
- How mobile-first CSS keeps the base styles simple and adds layout with `min-width` queries.
- When to reach for Flexbox (one direction) and when for Grid (rows and columns together).
- How the box model (`box-sizing: border-box`) makes sizing predictable.
